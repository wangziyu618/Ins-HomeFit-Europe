# 真实运营验证方案

## 最小可行目标

90 天内判断这个定位能否稳定产生目标人群的保存、主页访问和关注，并形成可持续的内容生产效率。

## 内容实验矩阵

每轮只改变一个主要变量，每个版本至少重复 3 次，减少单条内容偶然爆发的影响。

| 实验 | 固定项 | 变量 | 主指标 | 次指标 |
|---|---|---|---|---|
| Hook | 主题、格式、发布时间 | 痛点式 / 结果式 / 挑战式 | 3 秒留存或视频开始率 | 完播率 |
| 格式 | 主题、CTA | Reels / Carousel | 有效触达 | 保存率 |
| CTA | 素材、文案主体 | 保存 / 关注 / 评论关键词 | 对应转化率 | 负面反馈 |
| 市场 | 创意与预算 | DE / UK / NL | 目标人群触达成本 | 关注成本 |
| 共创 | 主题和产品 | 自制 / 创作者共创 | 有效互动率 | 素材复用率 |

## 每条内容必须记录的字段

post_id、published_at、market、language、content_pillar、format、hook_type、cta_type、organic_or_paid、spend、production_hours、reach、target_reach、plays、watch_time、completions、likes、comments、saves、shares、profile_visits、follows、experiment_id、variant、notes。

## 决策规则

- 某个结论至少由 3 次重复发布支持，并同时查看绝对量与转化率。
- 不用跨格式的原始点赞数判断胜负，因为算法分发和分母不同。
- 若一个主题有高播放但低主页访问，将其视为“有传播、弱定位”。
- 若有高保存但低关注，检查账号主页和内容连续性。
- 若付费放大后关注成本明显恶化，分开报告自然与付费结果。
- 90 天后只有在效果可重复、生产成本可承受时扩大频次。

## 周报模板

1. 本周决定验证的假设。
2. 发布了哪些版本，哪些变量保持一致。
3. 主指标结果与样本量。
4. 可以做出的结论及其置信程度。
5. 下一周只调整哪一个变量。
6. 数据异常、平台变化或执行偏差。

## 对当前模拟看板的处理

当前看板保留为界面和指标口径原型，并在页面顶部标注“模拟数据”。真实数据接入后，应删除所有预设增长曲线、随机波动和行业对标结论，由真实导出重新生成。
