HOMEFIT / EUROPE
90-DAY GROWTH CASE
Social Growth Portfolio

让居家健身内容从“能发”变成“可验证”

面向欧洲忙碌上班族，围绕“15 分钟、无需器械”建立内容系统。项目重点是定位、实验设计与复盘能力，而不是堆叠社媒指标。

CORE DECISION

先验证内容是否带来保存与主页访问，再扩大发布频次。

用单变量测试找到可重复的 Hook、内容格式和 CTA。

项目一眼看懂

把复杂数据压缩成 HR 和业务负责人都能理解的执行范围。

周期90 天从定位到复盘
目标市场3 个德国 / 英国 / 荷兰
内容支柱4 类痛点、教学、挑战、习惯
验证重点3 项保存、主页访问、关注

从问题到动作

每一步都对应一个明确判断，避免用单条爆款替代长期策略。

01 / POSITIONING

聚焦具体生活场景

以“没时间去健身房”的欧洲上班族为核心，减少泛健身内容竞争。

02 / TESTING

一次只改一个变量

固定主题与发布时间，分别测试 Hook、格式与 CTA，确保结果可以解释。

03 / SCALE

只放大可重复结果

连续三次获得有效保存或主页访问的主题，才进入模板化生产。

互动不是最终答案，用户下一步做了什么才是。

点赞适合观察内容吸引力；保存、主页访问和关注更接近内容对账号增长的真实贡献。

指标优先级

保存率高意图
主页访问率定位兴趣
关注转化率账号承接
点赞率辅助观察

下一步真实执行

用平台后台导出替换场景数据后，按同一套口径持续复盘。

建立内容编码

每条内容记录市场、Hook、格式、CTA、制作时间与实验编号。

运行三轮复测

每个版本至少重复三次，再判断是否形成稳定模式。

形成资源决策

以有效触达和关注成本决定增加、调整或停止。
