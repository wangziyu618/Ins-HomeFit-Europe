# HomeFit Europe：90 天 Instagram 运营实验设计

> 作品集案例｜内容系统、实验设计、数据口径与复盘模板

## 项目定位

这是一个面向欧洲上班族居家健身场景的**模拟运营案例**。账号、粉丝、触达和互动数据均为模拟值，没有真实发布行为，也不能用于证明账号增长或内容效果。

项目保留的价值是：把“无器械、15 分钟、上班族”这个定位拆成可执行的内容生产系统，并提前设计真实运营所需的实验、埋点和复盘方法。

## 要验证的业务问题

1. “15 分钟、无需器械”是否足以让目标用户保存、关注或访问主页？
2. Reels、Carousel 和 Static 在触达、收藏、关注转化上的职责是否不同？
3. 德国、英国和荷兰中，哪个市场的内容响应与获客成本更好？
4. 哪些创意元素真正推动结果：Hook、动作难度、场景、时长，还是 CTA？

## 90 天执行方案

| 阶段 | 目标 | 动作 | 决策 |
|---|---|---|---|
| 1–14 天 | 找到内容问题匹配 | 每个内容支柱发布 3–4 条，统一记录 Hook、格式和 CTA | 淘汰没有保存或主页访问的主题 |
| 15–45 天 | 验证格式与包装 | 每次只改变一个变量，重复有效主题 | 形成可复用内容模板 |
| 46–75 天 | 验证增长渠道 | 创作者共创、小额放大、跨平台分发 | 比较关注成本与有效互动 |
| 76–90 天 | 验证稳定性 | 复测 Top 主题，检查是否可重复 | 决定扩大、调整或停止 |

完整实验矩阵见 [真实运营验证方案](strategy/真实运营验证方案.md)。

## 核心指标口径

- **有效触达**：目标国家与目标年龄段的非粉丝触达。
- **保存率**：保存数 ÷ 触达，用于判断内容是否有复用价值。
- **主页访问率**：主页访问 ÷ 触达，用于判断内容是否建立兴趣。
- **关注转化率**：新增关注 ÷ 主页访问，用于判断账号定位是否清楚。
- **有效互动率**：（评论 + 保存 + 分享）÷ 触达。点赞单独展示，避免高估意图。
- **内容生产效率**：每小时制作带来的有效触达、保存或新增关注。

## 关于现有数字

仓库中“4,253 粉丝”“6.61% 互动率”“85 万触达”等数字由脚本生成，只用于展示数据结构和看板交互，不是运营成绩。由这些数字导出的“Carousel 最好”“20:00 最佳”等结论也只是演示性输出，真实账号需要通过受控发布测试重新验证。

## 真实运营接入方式

真实账号启动后，将 data/ 中的模拟文件替换为每周平台导出，并为每条内容增加 experiment_id、目标市场、Hook、内容支柱、CTA、制作工时和是否付费放大等字段。先冻结指标定义，再运行实验，避免结果出来后更换口径。
